# Vehicle Cost (用车成本记录)

Vehicle Cost 是一款极简、纯粹且无广告的车辆开销记录与陪伴 App。专注于为您提供最清晰的账单明细和用车统计，不捆绑任何冗余的社交或资讯功能。

## 核心特性
- **爱车陪伴**: 设置购车日期后，系统会自动计算您与爱车的陪伴天数。首页支持上传您的专属爱车照片。
- **纯粹记账**: “三大金刚”（加油、停车、洗车）优先排列，最快 3 秒即可记录一笔花销。
- **停车标签**: 停车费自带“固定月租”与“临时停车”标签细分，满足不同的统计需求。
- **全局视野**: 支持按「月份」和「年度」查看历史账单，并自带支出占比进度条，钱花在哪了一目了然。
- **数据安全**: 所有数据均通过 Room 数据库保存在本地沙盒，照片也会自动拷贝至应用私有目录，不索取不必要的隐私权限，安全可靠。

## 技术栈 (纯本地、现代化 Android 架构)
- **UI 框架**: 100% Jetpack Compose (Material Design 3)
- **架构模式**: MVVM + Unidirectional Data Flow (UDF)
- **数据持久化**: 
  - Room (SQLite) 承载核心的结构化账单流水
  - Jetpack DataStore 承载应用设置与车辆基础档案
- **图片加载**: Coil 异步加载引擎
- **路由导航**: Navigation Compose 实现三大底栏 (Bottom Navigation) 无缝切换

## 本地编译运行指南
1. 使用 Android Studio (建议 Koala 及以上版本) 打开本项目。
2. 本项目使用 Kotlin 2.0+ 与 KSP 作为注解处理器，如遇到同步缓慢请配置合理的 Gradle 代理。
3. 点击 `Run 'app'` 即可在真机或模拟器上运行。
