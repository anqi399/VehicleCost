# 爱车账本 (原 Vehicle Cost)

爱车账本是一款极简、纯粹且无广告的车辆开销记录与陪伴 App。我们致力于提供最清晰的账单明细和用车统计，拒绝捆绑任何社交或冗余的社区功能。

## 🚀 核心特性 (v2.1)
- **三大板块底栏导航**：爱车主页 (看板)、历史流水 (明细)、设置 (档案)。
- **纯手绘可视化**：使用 Compose Canvas 原生绘制的高性能“饼图”，无任何沉重的第三方图表依赖。
- **智能周期分析**：支持【本周 / 本月 / 本年】分段查看，并自带与上个周期的**环比趋势**（↑/↓）。
- **沉浸式记账**：点击加号秒弹金额小键盘（自动对焦）；点击保存伴有精妙的物理触感震动（Haptics）和毛玻璃成功气泡。
- **账单流水管理**：支持顶部横滑分类 Tag 筛选，数据自动按天生成“吸顶 (Sticky Header)”的日期分组。
- **历史数据导入**：支持极速读取内置 JSON 格式的历史账单模板并一键灌入数据库。

## 🛠 技术栈与架构 (致后来接手的 AI 或开发者)

本工程采用现代化的 **纯 Android 本地** 技术栈，结构极度轻量，请在后续迭代中**务必保持这种极简克制**的风格：
- **UI 框架**: 100% Jetpack Compose (Material Design 3)
- **架构模式**: MVVM + 严格单向数据流 (UDF)
- **数据库**: Room (SQLite)
- **配置持久化**: Jetpack DataStore (Preferences)
- **图片加载**: Coil-Compose (支持沙盒内部图片加载)

### ⚠️ 接手开发避坑指南 (AI Handover Notes)
1. **关于图表 (Pie Chart)**：
   不要为了画图引入 MPAndroidChart 或 Vico！目前的饼图是在 `DashboardScreen.kt` 中手写的纯 Canvas 代码。如果后续需要折线图，请优先用 Canvas 原生画线，以保持打包体积的极致小巧。
2. **关于 Room 数据库迁移 (Migration)**：
   目前数据库处于 `version = 2`。V1 升 V2 时加入了 `tag` 字段（主要用于细分“固定月租”等标签）。如果你要在 `VehicleCost.kt` 实体中增加新字段（如“行驶里程”），**必须**在 `AppDatabase.kt` 中提供合法的 `Migration(2, 3)` 脚本，绝对不允许 `fallbackToDestructiveMigration()` 清空用户的宝贵账单数据！
3. **不要污染业务逻辑**：
   目前的 UI 层不直接查询数据库，所有操作（分类筛选、按月筛选、同环比计算）均通过 `CostViewModel` 中精巧的 Flow 操作符（如 `combine` 和 `flatMapLatest`）组装。新增筛选维度时，请延续该流式处理风格。

## 📦 历史数据模板一键导入指南

为了方便您（或其他用户）从手机便签、Excel 等历史介质迁移数据，我们在应用内写死了一个极速 JSON 解析模块。

**操作步骤**：
1. 准备您的历史数据，并使用任意 LLM 将其转化为标准的 JSON 数组（注意金额抵扣说明可以放在 `note` 中）。
2. 打开工程的 `app/src/main/assets/import_template.json`。
3. 将格式化好的 JSON 粘贴进去。格式必须严格遵守如下结构：
   ```json
   [
     {
       "dateStr": "2025-11-16", // 必须是 yyyy-MM-dd 格式
       "category": "加油",     // 必须为内置的几种分类之一
       "amount": 225.0,        // 必须为浮点数
       "note": "实付225，原价250", // 选填
       "tag": "临时停车"         // 选填
     }
   ]
   ```
4. 编译并运行 App。
5. 前往 App 的**【设置】**页，点击**【一键导入历史账单】**，数据将在 1 秒内无损落库。
*(导入完成后，如果您不想其他人误碰，您可以注释掉 `SettingsScreen.kt` 中的该入口)*
